## 交付与本机试用

Chrome/Edge 构建均保持仅五个准确 `www` 可选域名，无通配子域、无安装即授予的网站权限。ZIP 和源码包需通过打包脚本的清单检查、SHA-256 及逐项解压内容校验。设置页/弹窗/安装截图和原创合成演示由本轮生产扩展重新生成。

本机专用 Edge 试用目录保留原 profile 与扩展路径，仅更新扩展文件，因此可沿用原扩展标识和原有 B站、小红书偏好；新增三站不自动授权。试用目录不纳入源码包。
