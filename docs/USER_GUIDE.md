# 安装与使用

## 加载扩展

从仓库 Releases 下载当前版本的 Chrome 或 Edge ZIP，解压到长期保留的目录。在 `chrome://extensions` 或 `edge://extensions` 打开开发者模式，点击“加载已解压的扩展”，选择包含 `manifest.json` 的目录。

不要直接加载 ZIP，也不要选择源码 ZIP。浏览器持续使用该目录内的文件；移动或删除目录后需要重新加载。

如果从源码构建，执行：

```sh
npm ci
npm run build
npm run build:edge
```

然后分别加载 `.output/chrome-mv3` 或 `.output/edge-mv3`。

## 第一次启用

全新安装后，B 站、小红书、百度、CSDN、知乎五站都处于关闭状态。从 0.1.x 更新时，原有两站设置保留，新增三站默认关闭。打开静流设置，启用需要的网站，并在浏览器提示中允许访问该站点。取消授权时，扩展应显示未获得权限的状态，网站继续正常显示。

只用其中一个网站时，可以只授权该网站。五站分别申请准确的 `www` 域名，不申请其他子域名。开启后打开或刷新对应网站，检查适配页面及需要保留的功能。

## 启用、授权与模式

| 状态       | 含义                           | 如何处理                       |
| ---------- | ------------------------------ | ------------------------------ |
| 站点关闭   | 不应用隐藏规则                 | 开启该站点即可启用             |
| 站点未授权 | 浏览器不允许扩展在该网站运行   | 从静流的启用操作请求授权       |
| 搜索优先   | 按默认组合隐藏支持的推荐模块   | 可以直接搜索，或主动打开内容   |
| 自定义     | 调整了一个或多个模块的隐藏开关 | 按需要恢复单项，或恢复搜索优先 |
| 临时放行   | 该站点在截止前暂时恢复原显示   | 等待到期或点击“提前结束”       |

设置中的模块开关表示“是否隐藏该模块”：打开开关会隐藏，关闭开关会恢复。它与网站的总启用开关不同。

## 搜索和主动浏览

搜索优先会收起首页推荐和默认热搜，让正常搜索仍可使用。输入关键词后的正常联想建议应保留。搜索结果、收藏、主动打开的视频、笔记详情不是需要清除的推荐首页。

B 站可以单独恢复“播放页相关推荐”；播放器、选集和评论属于需要保留的功能。小红书的推荐流和分类导航分开设置。

## v0.2 新增网站怎么用

| 网站         | 打开哪里查看效果                  | 可以调整什么                 | 保留范围与限制                                                                                                                                 |
| ------------ | --------------------------------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 百度         | `https://www.baidu.com/`          | 首页热搜                     | 保留原站搜索框及输入后的联想。搜索结果页整体保留；默认占位词和结果页侧栏未纳入                                                                 |
| CSDN         | `https://www.csdn.net/`           | 首页内容推荐、首页侧栏推广   | 收起首页资讯标题/头条/轮播链接、开源项目、精选博客及侧栏社区/直播/课程推荐。保留工具栏搜索、侧栏导航和含 iframe 的广告；`blog.csdn.net` 不注入 |
| 知乎（试验） | `https://www.zhihu.com/` 或问题页 | 首页推荐、问题页侧栏相关推荐 | 保留问题/回答正文和评论；搜索、关注、收藏、个人页保留，专栏域名不注入。真实访问遇到登录跳转或 HTTP 403，**待登录实测**                         |

百度首页热搜与 CSDN 首页模块的定位依据来自公开页面；本地样例测试不代表登录态或所有真实页面已经验收。知乎规则使用保守模块选择器，界面中的“试验”提示不会因开关打开而变成验证通过。需要登录时由你自行登录；不能访问时记录为受站点限制。

新增规则不提供整站广告拦截，也不承诺清除所有推广。请先在支持的首页分别切换单项模块，确认需要保留的搜索和内容入口正常。

当前版本使用固定的站点模块，不提供自由点选网页元素或导入共享规则。

## 临时放行 10 分钟

点击“放行一下”后，当前站点的隐藏规则暂停 10 分钟，已打开的该站点页面也应更新。其他站点不受影响。

截止时间保存在本地，以实际时间计算。关闭弹出面板不会重新计时；临时关闭后台也不会把它变成无限放行。重新打开面板时会根据截止时间显示当前状态。

点击“提前结束”会重新应用原有模块选择，不会重置自定义设置。若关闭整个站点，关闭状态优先。

## 关闭、撤销权限和重置

- **关闭站点：** 停止对该站点应用隐藏规则，并恢复页面显示。
- **撤销权限：** 在浏览器扩展详情中管理网站访问；静流需要重新获得授权后才能再次作用于网页。
- **恢复搜索优先：** 恢复该站点的默认隐藏组合，并清除临时放行状态；保留当前启用状态。需要停止隐藏时请关闭网站的启用开关。
- **卸载：** 在扩展管理页移除静流，同时删除其本地扩展设置。

## 页面没有变化

依次检查：是否为桌面版支持网站、是否已启用对应站点、浏览器是否已授权、是否处于临时放行，以及对应模块的隐藏开关是否打开。再刷新页面确认。

页面结构变化可能让某个模块暂时匹配不到。扩展面板中的匹配状态只反映当前页面的规则检测，不证明整个网站都兼容。可以关闭该模块，并按 [贡献指南](../CONTRIBUTING.md) 提供浏览器版本、页面类型和复现步骤。

静流不负责绕过站点的登录要求、风控或网络限制。小红书、百度搜索、知乎等页面未登录时能否打开，由原站决定。详细检查范围见 [验收清单](VALIDATION.md) 与 [百度](evidence/baidu.md)、[CSDN](evidence/csdn.md)、[知乎](evidence/zhihu.md) 的结构探测记录。

## 更新本地加载的版本

先下载并验证新版本，解压到原加载目录，保持目录路径不变；然后在浏览器扩展管理页点击重新加载，并刷新网页。保留同一加载目录可减少扩展标识和设置发生变化的情况。

如新版本提示配置来自更新的格式，不要手动删除设置；应使用相应的新版本。版本回退前请先记录当前模块选择。
