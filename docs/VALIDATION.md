# 手工真实网站验收清单

这份清单用于在自己的浏览器中验证 v0.2.0 的实际网站。自动化使用的本地 HTML 样例不代表真实站点、登录态或所有浏览器已通过。未执行的项目保持“未验收”，不根据界面截图推断结果。v0.1 的历史真实网站结果保留在 [验证记录](VERIFICATION.md)，不自动转为本版通过。

本版五站分别授权、默认关闭。新增范围仅为百度首页热搜、CSDN 首页指定模块，以及知乎试验规则；知乎待登录实测。结构探测详情见 [百度](evidence/baidu.md)、[CSDN](evidence/csdn.md)、[知乎](evidence/zhihu.md)。

## 1. 安装和首次权限

- [ ] Chrome：解压 Chrome ZIP，加载包含 `manifest.json` 的目录，设置页和弹出面板可用。
- [ ] Edge：解压 Edge ZIP，加载包含 `manifest.json` 的目录，设置页和弹出面板可用。
- [ ] 全新安装后，五个网站都关闭，网页保持原显示。
- [ ] 从 0.1.x 更新时，B 站和小红书原设置保留，百度、CSDN、知乎均关闭且未自动授权。
- [ ] 逐站启用，只出现该站准确 `www` 域名的权限提示，其他四站状态不变。
- [ ] 浏览器中没有百度其他子域、`blog.csdn.net` 或 `zhuanlan.zhihu.com` 的授权请求。
- [ ] 取消站点授权后，不显示“已生效”；原网页可正常浏览。
- [ ] 浏览器扩展详情中不存在五个准确站点域名之外的网站访问请求，也没有通配子域名。

## 2. B 站页面

分别在未登录、已登录状态执行。无法访问或遇到站点风控时，记录为“受站点限制”，不要标为通过。

- [ ] 首页默认搜索优先：推荐视频列表隐藏，页面没有大块无法操作的遮挡。
- [ ] 轮播与推广开关只控制对应区域。
- [ ] 热门与排行入口隐藏后，正常导航和搜索仍可操作。
- [ ] 未输入关键词时默认热搜隐藏；输入后的正常联想可用。
- [ ] 输入关键词并搜索：结果列表可见，能打开视频。
- [ ] 视频页：播放器可播放，选集可切换，评论可查看，相关推荐按设置隐藏。
- [ ] 连续播放或选集列表没有被当作相关推荐一起移除。
- [ ] 从搜索结果直接打开视频、新标签页打开视频，均可使用。
- [ ] 动态、个人空间及收藏入口可正常打开，没有被首页规则误伤。
- [ ] 从首页进入视频再返回首页，多次切换后模块状态一致。
- [ ] 分别关闭每个隐藏模块，只有对应区域恢复，其他模块不受影响。

## 3. 小红书页面

同样记录未登录与已登录的实际覆盖。站点要求登录时，先记录此限制；只有自行登录并实际执行后，才能补充登录态结果。

- [ ] 发现页推荐流隐藏，搜索入口可用。
- [ ] 分类推荐导航可以单独隐藏和恢复。
- [ ] 默认热词隐藏，输入后的正常搜索联想保留。
- [ ] 搜索结果列表可见，可以打开笔记详情。
- [ ] 从搜索结果、复制的直接链接分别打开笔记，正文、图片/视频、评论可见。
- [ ] 关闭笔记详情返回原页面后，搜索结果未被误删。
- [ ] 从发现页切换到搜索再返回，多次切换后规则仍按页面类型生效。
- [ ] 调整其中一个模块时，没有隐藏整个站点的主体容器。

## 4. 百度页面

分别记录未登录和已登录的真实结果。搜索跳转到安全验证时记为“受限”，不要将验证码页面当作结果页验收通过。

- [ ] 桌面首页热搜标题和列表隐藏，原站搜索框与搜索按钮可操作。
- [ ] 点击搜索引导能聚焦原站搜索框，没有额外创建搜索入口或篡改关键词。
- [ ] 输入关键词后的联想建议正常显示。
- [ ] 关闭“首页热搜”后同一批原站节点恢复，重新开启后再次隐藏。
- [ ] 搜索结果页整体保留原样，包括结果和右侧辅助内容。
- [ ] 登录、安全验证和其他百度子域保持原样，没有被热搜规则隐藏。
- [ ] 首页进入搜索再返回，隐藏状态与模块开关一致。

## 5. CSDN 页面

当前权限仅覆盖 `www.csdn.net`；博客文章所在的 `blog.csdn.net` 不注入。本版不提供文章页整理功能。

- [ ] 桌面首页的资讯标题/头条/轮播链接、开源项目、精选博客按设置隐藏，工具栏搜索与侧栏导航可操作。
- [ ] “首页内容推荐”和“首页侧栏推荐”两项可独立切换；侧栏只控制社区、直播和课程推荐。
- [ ] 含 iframe 的广告、活动日历和其他页面内容保留；没有因规则未匹配而扩大隐藏。
- [ ] 从首页使用原站搜索，结果可见；搜索所在的其他域名不注入。
- [ ] 打开博客文章，正文、代码、目录、评论保持原样，弹出面板不将该域名标为已适配。
- [ ] 原站登录与验证码可正常使用。
- [ ] 关闭站点、刷新和前进后退后，页面显示与设置一致。

## 6. 知乎试验页面

本版界面必须显示“试验”及待登录实测提示。此前真实访问只得到登录跳转或 HTTP 403，未取得推荐内容实测；由使用者自行登录。无法访问时保持“受限”，不能标为效果通过。

- [ ] 设置页明确提示知乎是试验适配，且默认关闭。
- [ ] 登录页及验证码完全保留，登录过程没有被隐藏规则干扰。
- [ ] 登录后首页只收起明确匹配的推荐条目，搜索框可用。
- [ ] 用户主动打开的关注、热榜、搜索、个人主页和收藏页保留原样。
- [ ] 问题页只有已知的侧栏相关推荐按设置隐藏，问题、回答正文和评论可见。
- [ ] 分别关闭两项模块，只有对应区域恢复；未知结构报告未匹配，不隐藏整个内容根节点。
- [ ] 新标签页直接打开回答，正文、评论与原站导航可用。
- [ ] 知乎专栏 `zhuanlan.zhihu.com` 不请求权限、不注入，文章保持原样。
- [ ] 首页、问题页与搜索之间跳转及返回，规则仍按页面类型应用。

## 7. 临时放行与恢复

- [ ] 逐站点击“放行一下”，该站页面恢复原显示，其他四站设置不变。
- [ ] 同一站点两个标签页都更新，无需分别点击。
- [ ] 关闭再打开弹出面板，剩余时间继续减少，没有重置为 10 分钟。
- [ ] 点击“提前结束”，原模块选择重新生效。
- [ ] 等待实际 10 分钟，模块自动恢复；记录计时起止时间。
- [ ] 浏览器后台服务休眠后再次打开页面，按保存的截止时间计算状态。
- [ ] 放行期间关闭站点，再打开面板，显示关闭状态。
- [ ] 多站分别放行时，截止时间和恢复操作互不影响。

## 8. 禁用、撤权、更新

- [ ] 当前页面开着时关闭站点，隐藏内容恢复，页面无需重新登录。
- [ ] 在扩展管理页撤销站点权限，扩展显示未授权且不继续注入。
- [ ] 重新授权后可恢复所选模块，没有复制多份样式或提示。
- [ ] 逐站点击“恢复搜索优先”，恢复该站默认隐藏组合、结束该站放行并保留其启用状态；其他四站自定义设置仍在。
- [ ] 刷新网页、重新打开浏览器后，设置正确保留。
- [ ] 使用原加载目录更新扩展并点击重新加载，设置与页面状态一致。
- [ ] 在不支持的网站打开弹出面板，说明当前站点不适用，不申请该网站权限。

## 9. 可访问性与界面

- [ ] 仅用键盘可到达按钮、开关和设置入口，焦点可见。
- [ ] 200% 缩放时主要文字和操作没有被裁切。
- [ ] 状态通过文字表达，不仅依靠颜色。
- [ ] 浏览器拒绝授权或后台返回错误时，界面有可理解的说明。
- [ ] 站点找不到某模块时，面板没有把“未匹配”写成整个网站已通过。
